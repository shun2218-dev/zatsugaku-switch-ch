1. 前提 / Scope

AutoTube Studio（以下「本ツール」）は、個人の運営者が自身の YouTube チャンネルを管理するために利用する 単一ユーザーの非公開ツールです。本ツールに第三者のユーザーは存在せず、 取り扱うデータは運営者本人のアカウント・チャンネルに関するもののみです。

AutoTube Studio ("the Tool") is a private, single-user application used by an individual operator to manage their own YouTube channel. There are no third-party users; all data handled by the Tool relates solely to the operator's own account and channel.

2. YouTube API Services の利用 / Use of YouTube API Services

本ツールは YouTube API Services を利用しています。本ツールを利用（API アクセスを認可）することにより、利用者は YouTube 利用規約 に同意したものとみなされます。また、Google のプライバシー慣行は Google プライバシーポリシー をご確認ください。

The Tool uses YouTube API Services. By authorizing the Tool, you agree to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

3. 取得・保存するデータ / Data We Access and Store

  • OAuth トークン: 運営者のチャンネルへアクセスするための認可トークン。運営者のローカル環境にのみ保存
  • チャンネル情報: チャンネルID・チャンネル名
  • アップロードした動画のメタデータ: 動画ID・タイトル・公開状態
  • 視聴実績データ（YouTube Analytics）: 運営者自身のチャンネルの再生数・視聴維持率・登録者増減等の日次レポート

The Tool stores: OAuth tokens (kept only on the operator's local machine), the operator's channel ID and name, metadata of uploaded videos (video ID, title, privacy status), and daily YouTube Analytics reports (views, retention, subscriber changes) for the operator's own channel. All data is stored in a local database on the operator's machine. The Tool does not use cookies and does not collect data from any third party.

4. データの利用目的 / How Data Is Used

取得したデータは、(1) 運営者のチャンネルへの動画アップロード、(2) 視聴実績にもとづくコンテンツ改善分析、 のためにのみ利用します。第三者への提供・共有・販売は一切行いません。 広告目的の利用も行いません。

Data is used only to (1) upload videos to the operator's own channel and (2) analyze the channel's performance to improve content. Data is never shared with, transferred to, or sold to any third party, and is not used for advertising purposes.

5. 保存期間と更新 / Retention and Refresh

視聴実績データは日次バッチで YouTube Analytics API から再取得・更新されます。 保存されたデータは、API アクセスの認可が取り消された場合、または運営者が削除を決定した場合に削除します。

Analytics data is refreshed daily from the YouTube Analytics API. Stored API data is deleted when authorization is revoked or upon the operator's decision to delete it.

6. アクセスの取り消しとデータ削除 / Revoking Access and Data Deletion

本ツールへの認可は、Google のセキュリティ設定ページ （https://myaccount.google.com/permissions） からいつでも取り消せます。取り消し後、保存済みの API データおよびトークンは7日以内に削除します。 データ削除のご依頼は下記連絡先でも受け付けます。

You can revoke the Tool's access at any time via the Google security settings page (https://myaccount.google.com/permissions). After revocation, stored API data and tokens are deleted within 7 days. Deletion requests are also accepted at the contact address below.
