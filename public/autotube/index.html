サービス概要 / About

AutoTube Studio は、YouTube チャンネル「雑学スイッチ」を運営するための個人利用・単一ユーザーの動画制作支援ツールです。 企画の立案、ナレーション音声・背景画像の生成、動画の合成、YouTube への限定公開（unlisted）アップロード、 および視聴実績の分析を、運営者本人の管理下で行います。

AutoTube Studio is a private, single-user video production tool operated by an individual developer to manage their own YouTube channel. It assists with video planning, narration/background generation, video composition, uploading videos as unlisted to the operator's own channel, and analyzing the channel's performance data.

YouTube API Services の利用について / Use of YouTube API Services

本ツールは YouTube API Services を以下の目的で利用します。

  • YouTube Data API: 運営者自身のチャンネルへの動画アップロード（既定は限定公開）とメタデータ設定
  • YouTube Analytics API: 運営者自身のチャンネルの視聴実績（再生数・視聴維持率等）の取得と改善分析

This tool uses the YouTube Data API to upload videos (unlisted by default) and set metadata on the operator's own channel, and the YouTube Analytics API to retrieve the operator's own channel performance reports for content improvement. It accesses only the channel owned by the operator, with the operator's explicit OAuth consent. No third-party user data is accessed.

コンテンツについて / Content

生成する動画はAI技術（大規模言語モデル・音声合成・画像生成）を活用して制作しており、 その旨を各動画の概要欄に明記しています。すべての動画は公開前に人間（運営者）による確認・承認を経ます。

Videos are produced with the assistance of AI technologies (LLM scripting, speech synthesis, image generation), and this is disclosed in each video's description. Every video is reviewed and approved by the human operator before being made public.
