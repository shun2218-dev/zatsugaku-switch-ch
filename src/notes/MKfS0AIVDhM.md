### 空気が、いちばん熱を伝えない

大阪教育大学の資料に載っている熱伝導率（W/m・K）を並べると、空気の特殊さがわかります。

| 物質 | 熱伝導率 |
| --- | --- |
| 銅 | 403 |
| アルミニウム | 236 |
| 鉄 | 83.5 |
| 水（10℃） | 0.582 |
| 乾燥木材 | 0.15〜0.25 |
| **乾燥空気（0℃）** | **0.0241** |

同じ資料は、物質の状態による傾向も書いています。

> 熱伝導率は、気体、液体、固体の順の大きくなります。

気体がいちばん小さい。そして身のまわりにある気体といえば空気です。

つまり、**何かを断熱したいなら空気を使うのが最善**ということになります。

### ウールの縮れは、空気を閉じ込める構造

ウールの繊維には、天然のちぢれ（クリンプ）があります。まっすぐではなく、波打っています。

この縮れがあると、繊維同士がぴったり密着できません。繊維の間に無数の隙間ができ、そこに空気が入ります。

さらにウールの表面には鱗のような構造（スケール）があり、繊維同士が絡み合いやすい。だから紡いだ糸はふんわりとかさばり、たくさんの空気を抱えます。

セーターの重さの大半は繊維ですが、体積の大半は空気です。暖かさを担っているのは、その空気のほうです。

### 大事なのは「動かない空気」

ここに条件があります。閉じ込められた空気が**動かない**ことです。

空気が自由に動けると、温められた空気が上昇し、冷たい空気が入ってきます。対流です。対流が起きると、熱は空気の流れに乗って運ばれてしまい、断熱になりません。

だから断熱材は「空気をたくさん含む」だけでなく「空気が動けないように小分けにする」という条件を満たす必要があります。

- **ウール**: 縮れた繊維の隙間に空気を分散して閉じ込める
- **羽毛**: 細い枝分かれが空気を小さな区画に分ける
- **発泡スチロール**: 独立した気泡に空気を閉じ込める
- **グラスウール**: 細い繊維の絡み合いで空気を保持する

どれも同じ戦略です。素材の正体は「空気の保持具」です。

### だから濡れると暖かくなくなる

セーターが濡れると、途端に寒くなります。理由は数字で説明できます。

空気の熱伝導率は0.0241。水は0.582。**24倍**です。

繊維の隙間に入っていた空気が水に置き換わると、そこは24倍熱を伝える物質になります。断熱材だったものが、熱の通り道になってしまう。

さらに水が蒸発するときには、気化熱として体から熱を奪います。濡れた衣類が危険なのは、この二重の効果です。

登山で「濡れは命に関わる」と言われるのは、断熱が失われるだけでなく、積極的に熱を奪われるからです。

### ウールの強みは「濡れにくい」こと

ただし、ウールには綿と違う性質があります。

ウールの繊維の表面は水をはじき、水分は繊維の内部に吸収されます。だから表面的には濡れても、繊維の間の空気の層が比較的残りやすい。綿は繊維の隙間まで水が入り込むので、空気の層が一気に失われます。

「ウールは濡れても暖かい」と言われるのは、この構造の差です。濡れれば断熱性は確実に落ちますが、綿より落ち方が緩やかだということです。

また、ウールは水分を吸うときに熱を出す性質（吸湿発熱）も持っています。繊維が水蒸気を吸着する際にわずかな熱が発生します。

### 「何を着るか」ではなく「どう空気を持つか」

実用的な結論は、こうなります。

厚い服1枚より、薄い服を重ねたほうが暖かい。重ねた服と服の間にも空気の層ができるからです。

ぴったりした服より、少しゆとりのある服のほうが暖かい。体と服の間に空気を保てるからです。ただしゆとりが大きすぎると、その空気が対流で動いてしまいます。

マフラーや手袋も、保温というより「空気の層を風から守る」役割が大きい。風が吹けば表面の空気の層が吹き飛ばされ、断熱が失われます。
